system-six

Black-and-white 1-bit desktop components in plain CSS. Put class="s6" on a container and the controls inside it draw in ink and paper, at the pixel sizes of the 1980s originals. Sharp draws them as pixel art; smooth (s6-smooth) keeps the strokes, frames, and shadows as vectors with squircle corners.

Every part draws at the original's physical size: one original pixel is 1/72 inch, set as the nearest whole number of this screen's pixels.
